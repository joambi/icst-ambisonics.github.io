## ZYLIA STUDIO

**ZYLIA Studio GmbH** ist eine Anwendung, die für die Arbeit mit ZM-1-Mikrofon bestimmt ist, das einen einfachen Workflow für die mehrspurige Aufnahme Ihrer Soundscape oder Musikband, die Trennung von Tonquellen und Mischspuren zur Vorbereitung einer ausgewogenen Aufnahme bietet.

### Desktop-Anwendung für MAC, Linux und Windows (auch Windows-Tablets)

### Nehmen Sie Ihre Aufnahmen auf, mischen und speichern Sie sie

### Einzelne Instrumente / Schallquellen in getrennte Spuren extrahieren

### Erstellen Sie eine ausgewogene Aufnahme, indem Sie die Lautstärke und das Schwenken einzelner Instrumente anpassen oder für die AUTOMIX-Option belassen

### Mehrere Exportmöglichkeiten (Row 19-Kanal-Aufnahme, Stereo-Mix, einzelne Solo-Tracks), in WAV (Wellenformat 48 kHz bis zu 32 Bit

### Polieren Sie Ihre Aufnahme in Ihrer Lieblings-DAW

  

![](https://www.youtube.com/watch?v=j4j-9yvf0q4)

### So beginnen Sie mit ZYLIA Studio

![](https://www.zylia.co/web/image/120248-7897854a/zs2-09.png)

In ZYLIA Studio 2.0 werden die Instrumente während der Aufnahme automatisch am Mikrofon erkannt und lokalisiert. Wählen Sie daher einfach Ihre bevorzugte Konfiguration aus: Band-, Surround- oder Mikrofontechniken.  

![](https://www.zylia.co/web/image/120247-50f04d42/ZYLIA%20Studio%202.0-1.jpg)

Auf dem Aufnahmebildschirm wird die Live-Nachverfolgung von Klangquellen und dynamischer Energiekarte angezeigt.  
  
Es wird empfohlen, den Gerätetyp durch Doppelklick auf das Sound-Source-Symbol auszuwählen, was die Ergebnisse der Automix-Funktion verbessert.  

![](https://www.zylia.co/web/image/120249-7afc8801/zs2-0-3_orig.png)

Musiker müssen ihre Instrumente nur in der richtigen Zone um das Mikrofon platzieren und die dynamische Energiekarte wird ihnen helfen, ihre Position zu verfolgen.

Wenn Sie die Aufnahmetaste drücken, wird nun eine Echtzeit-Wellenform erzeugt, während die Aufnahme ausgeführt wird.  

![](https://www.zylia.co/web/image/120250-432a4b16/zs2-0-4_orig.png)

Sie können den Aufzeichnungsprozess mit einem Webbrowser auf Ihrem Smartphone oder Tablet fernsteuern. Mit dieser Funktion können Sie ZYLIA Studio-Parameter wie die Überwachung des VU-Messgeräts steuern und Ihre Aufnahmen starten und stoppen.

![](https://www.zylia.co/web/image/120251-3e724cb3/zs2-0-5_orig.png)

Jetzt, selbst wenn Sie sich von Ihrem Computer entfernen, haben Sie alles zur Hand.  

![](https://www.zylia.co/web/image/120252-62154d7c/zs2-0-6.png)

Um zum Mix-Fenster zu gelangen, klicken Sie auf das Mix-Symbol auf Ihrem aufgenommenen Take.

Im Mixer-Fenster können Sie einzelne Instrumente in separate Spuren extrahieren und miteinander mischen.  

![](https://www.zylia.co/web/image/120253-d65d0537/zs2-0-7_orig.png)

Der Mixer bietet auch einen einfach zu bedienenden 3-Band-EQ für jede Klangquelle, Lautstärkepegel, Schwenk-, Solo- und Stummschaltungsoptionen für jeden getrennten Track.  
  
Erstellen Sie eine ausgewogene Aufzeichnung, indem Sie alle Parameter manuell anpassen oder für AUTOMIX belassen.  

![](https://www.zylia.co/web/image/120254-f4170ca9/zs2-0-8_orig.png)

Das Exportfenster bietet eine übersichtliche Ansicht Ihrer Dateiexportoptionen. Klicken Sie einfach auf Ihre bevorzugten Optionen gefolgt von der Schaltfläche Export unten.  
  
Mehrere Exportmöglichkeiten: Roh-19-Kanal-Aufnahmen, Stereo-Mix und einzelne Solo-Tracks stehen zum Download bereit.  

![](https://www.zylia.co/web/image/120255-7587c288/zylia-studio-2-0-9.jpg)

Das Aufzeichnen von Szenenanweisungen und sehr hilfreichen Tutorials wird Ihre Erfahrung verbessern.  

![](https://www.zylia.co/web/image/120256-4114e336/zs2-0-2_orig.png)

Das Aufzeichnen von Szenenanweisungen und sehr hilfreichen Tutorials wird Ihre Erfahrung verbessern.  

Drücken Sie esc, um den Vollbildmodus zu beenden

# Zylia Daten:

### Allgemein

- Anzahl Mikrofone: 19 digitale MEMS-Sensoren
- Abmessungen (inkl. Standfuß): Höhe - 155 mm (6,1''), Länge - 103 mm (4''), Gewicht - 470 g (16,6 Unzen)
- Anschluss an Computer: USB 2.0 (Typ A) auf microUSB 2.0 (Typ B)
- Versorgungsspannung: 5 V DC
- Strom und/oder Leistung: max. 0,5 A 2,5 W, 0,15 – 0,26 A (+/- 0,01 A)
    

### Mikrofone Spezifikation  

- Frequenzbereich: 20 – 20 000 Hz
- Dynamikbereich: 105 dB
- Signal-Rausch-Verhältnis (SNR): 69 dB(A)
- Gesamte harmonische Verzerrungen (THD): <1% bis zu 128dB SPL
- Akustischer Überlastpunkt: 130 dB SPL
- Direktivität: omnidirektional
- Geräuschpegel: -105 dB FS(A)

### A/D-Umwandlung  

- SS-Durchschnittsrate: 48 kHz
- Bitauflösung: 24-Bit
