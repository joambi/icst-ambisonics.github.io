# Partiels

Partiels is an application for the analysis of digital audio files intended for researchers in signal processing, musicologists, composers, and sound designers. It offers a dynamic and ergonomic interface in order to explore the content and the characteristics of sounds.

[Analysis](https://forum.ircam.fr/topics/detail/379-Analysis/)[Analysis of sound](https://forum.ircam.fr/topics/detail/481-Analysis%20of%20sound/)[Audiosculpt](https://forum.ircam.fr/topics/detail/134-Audiosculpt/)[Host](https://forum.ircam.fr/topics/detail/574-Host/)[Partiels](https://forum.ircam.fr/topics/detail/576-Partiels/)[Plugins](https://forum.ircam.fr/topics/detail/202-Plugins/)

* [Documentation](https://forum.ircam.fr/asset/935/Super%20Vamp%20Plugin%20Manual%20v1.pdf)

![[./_resources/Partiels__Ircam_Forum.resources/Partiels-0.0.9-4.png]]

Partiels allows **analysis** one or several audio files using _Vamp_ plugins (1), **loading** data files, **organizing** and **visualizing** the analyses inside groups, and **exporting** the results as images or text files (in order to be used in other applications such as _Max_, _Pure Data_, _Open Music_, etc.).

Discover the video [tutorials](https://forum.ircam.fr/article/detail/tutoriel-partiels/)!

![[./_resources/Partiels__Ircam_Forum.resources/Partiels-0.0.9-0.gif]]

Main features and characteristics:
\* Versions for _Windows_, _Mac_ & _Linux_
\* Multiformat & multichannel support
\* Multifile support (useful to compare audio files)
\* Analyzing audio with _Vamp_ plugins
\* Visualizing results as _spectrogram_, _lines_, and _markers_
\* Organizing and ordering analyses in groups
\* Exporting results to _PNG_, _JPEG_, _CSV_, _JSON_, _CUE_ & _SDIF_ file formats
\* Loading results from _CSV_, _JSON_, _CUE_ & _SDIF_ file formats
\* Converting results from _SDIF_ to _JSON_ file formats and inversely
\* Batch processing (useful to apply the same set of analyses on several audio files)
\* Command line interface to analyze, export and convert results
\* Consolidating documents (useful to share documents/analysis with other users across different platforms)
\* Audio playback with loop

Partiels is compatible with Windows 10 (64 bit), macOS (universal binary: Intel 64 bit and M1) and Linux (64 bit - tested on Debian 10.9, Ubuntu 20.04, 20.10 & 21.04).

_(1) Vamp is an audio processing plugin system for plugins that extract descriptive information from audio data developed at the Centre for Digital Music, Queen Mary, University of London._

![[./_resources/Partiels__Ircam_Forum.resources/Communication.png]]

Alongside Partiels, a set of analyses present in the AudioSculpt 3 application and based on the audio engines developed by the Ircam Analysis-Synthesis team are ported as Vamp plugins: [SuperVP Vamp Plugin](https://forum.ircam.fr/projects/detail/supervp-vamp-plugin/) & [IrcamBeat Vamp Plugin](https://forum.ircam.fr/projects/detail/ircambeat-vamp-plugin/).

**Vamp**: developed at the Centre for Digital Music, Queen Mary, University of London: [www.vamp-plugins.org](https://www.vamp-plugins.org/)
