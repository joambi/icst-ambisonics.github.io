### Distance Encoding

Distance encoding is an optional feature and can be enabled/disabled using the first checkbox. Distance encoding presets can be saved and loaded independently from other presets. For more information, see [Distance Encoding](https://bitbucket.org/christian_schweizer/icst-ambisonics-plugins/wiki/Distance_Encoding/)
