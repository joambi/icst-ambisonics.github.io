# ICST Ambisonics Workshop 2026 — Additional Materials

## Ordnerstruktur

```
workshop-2026/
├── act-tool/          → ACT-Tool.app (gezippt als ACT-Tool.zip)
├── reaper-setup/      → REAPER Workshop-Installation (ohne REAPER.app)
├── html/              → HTML-Seiten / interaktive Demos
├── csound/            → Csound-Instrumente (.csd)
└── maxmsp/            → Max/MSP Patches (.maxpat)
```

## Installation REAPER Workshop Setup

1. **REAPER.app** separat installieren → in `/Applications/ICST Ambisonics Workshop 2026/` ziehen
2. Den Inhalt von `reaper-setup/` ebenfalls in `/Applications/ICST Ambisonics Workshop 2026/` kopieren
3. REAPER über den Ordner starten
