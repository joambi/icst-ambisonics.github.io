# ICST HOA Verification Quick Guide

## 1. Check the session baseline
- Open the project.
- Confirm sample rate and audio device in Project Settings.
- Verify the channel count of the Master and HOA tracks in the routing window.

## 2. Check the decoder
- Insert the decoder on `DECODER MAIN`.
- Load the loudspeaker preset for the current setup.
- Confirm that output channels are mapped correctly to the hardware.

## 3. Run a one-source signal test
- Load a mono source onto `SRC 01`.
- Insert the ICST MonoEncoder.
- Route the source to the HOA bus.
- Move position or pan slightly and listen for the expected spatial movement.

## 4. Cross-check monitoring
- Test the loudspeaker path briefly.
- If available, check the binaural monitoring path as well.
- Listen for silence, jumps in level, or wrong speaker assignment.

## 5. Approve the session
- If source, HOA bus, and decoder behave as expected, the session is ready for recording, rehearsal, or export.
