# ICST HOA Verifikation Kurzanleitung

## 1. Session-Basis pruefen
- Projekt oeffnen.
- In den Project Settings Sample Rate und Audio-Device bestaetigen.
- Im Routing-Fenster die Kanalzahl von Master und HOA-Tracks kontrollieren.

## 2. Decoder pruefen
- Decoder auf `DECODER MAIN` einsetzen.
- Lautsprecher-Preset fuer das aktuelle Setup laden.
- Kurz pruefen, ob Ausgangskanaele sauber auf die Hardware gemappt sind.

## 3. Signalcheck mit einer Quelle
- Eine Monoquelle auf `SRC 01` laden.
- ICST MonoEncoder einfuegen.
- Quelle zum HOA-Bus routen.
- Panorama oder Position leicht bewegen und auf erwartete Raumbewegung achten.

## 4. Monitoring gegenhoeren
- Lautsprecherpfad kurz pruefen.
- Falls vorhanden, binauralen Kontrollpfad gegenhoeren.
- Auf Pegelspruenge, Stille oder falsche Lautsprecherzuordnung achten.

## 5. Freigabe
- Wenn Quelle, HOA-Bus und Decoder wie erwartet reagieren, ist die Session bereit fuer Aufnahme, Probe oder Export.
