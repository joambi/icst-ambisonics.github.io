**HowTo:**

* Install —>  listento-20200416-installer-osx-signed.pkg 

* Was ist das Listend-Plugin?
	* Listento ist ein von Audiomovers entwickeltes Software-Audio-Plug-In. Entwickelt, um Audiosignale von der DAW an eine Webbrowsersitzung oder an den Listento-Empfänger zu streamen. Listento ermöglicht Echtzeit-Streams für mehrere verlustfreie und komprimierte Formate. Plug-In in den Formaten VST, VST3, AU und AAX verfügbar.
* Wie benutze ich das Listend-Plugin?
	* Um das Listend-Plugin zu verwenden, wählen sie einfach die Spur (Audio oder Instrumental) und legen sie das Listend in den leeren Insert Slot.
	* Melden Sie sich mit Ihren Kontoeinstellungen an.
	* Sitzungsnamen festlegen;
	* Kopieren Sie den Link Ihrer Sitzung und senden Sie ihn an Ihren Kunden.
	* Klicken Sie auf die Schaltfläche Übertragung starten, um das Streaming zu starten.
* Was ist das Listento Receiver Plugin?
	* Listento Receiver ist ein Plugin, mit dem eingehende Audiostreams vom Remote-Listento-Plugin empfangen und aufgezeichnet werden können
* Wie verwende ich das Listento Receiver Plugin?
	* Um das Listento Receiver-Plugin zu verwenden, erstellen Sie einfach eine AUX-Spur.
		* Stecken Sie den Listento-Empfänger in den Insert-Slot der AUX-Spur.
		* Fügen Sie den Link ein.
		* Klicken Sie auf die Schaltfläche Verbinden. Jetzt sollten Sie das eingehende Signal hören können.
		Um eingehende Audiostreams vom Listento-Plug-In aufzuzeichnen
		* Verbinden Sie den AUX-Spurausgang mit dem Audiospur-Eingang.
		* Aufnahmearm Audiospur;
		* Starte die Aufnahme.
