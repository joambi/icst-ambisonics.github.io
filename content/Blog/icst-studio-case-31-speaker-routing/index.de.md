# ICST Studio-Case: Warum unser 31-Speaker-Setup so geroutet ist

**Für wen:** Level: Intermediate | Zielgruppe: Komponist:in, Techniker:in, Researcher.

## Kontext
Dieser Case beschreibt die Routing-Logik im ICST Kompositionsstudio, damit Sessions stabil und reproduzierbar bleiben.

## Kernentscheidungen
1. Dedizierter `Bformat-Master` als zentrale Instanz.
2. Decoder-Ebene klar von Quellen-Ebene getrennt.
3. Monitoring-Varianten (Speaker/Binaural) als parallele Pfade.
4. Einheitliche Benennung und Kanal-Konventionen.

## Was das löst
- Schnellere Einarbeitung für Gastkuenstler:innen
- Weniger Setup-Fehler
- Einfachere Fehlersuche in der Produktion

## Typische Fehlerstellen
- Gemischte Kanalformate auf dem Master-Pfad
- Monitoring von falschem Bus gespeist
- Decoder-Preset passt nicht zum Lautsprecher-Setup
