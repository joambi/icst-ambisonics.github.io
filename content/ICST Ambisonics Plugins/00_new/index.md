# ICST Ambisonics Plugins Release 4.0

We are pleased to present version 4.0.0 of our ICST Ambisonics plugins.

This release (v4.0.0) is a major step forward for composing in Ambisonics with source groups: create choreographies directly in the REAPER timeline and save them as XML scores, so you can reuse and reshape them in other projects. The ICST Group Animator is a "work in progress" and will continue to grow.

In the ICST AmbiEncoder_64 plugin we have also optimised the Blauert filters, and for a spherical presentation without a frontal orientation, the Z axis alone can be selected.
