## ICST Ambisonics Plugins

The core plugin suite for encoding and decoding Ambisonics B-format in REAPER. Free and open source.

- [Download latest release](https://github.com/schweizerweb/icst-ambisonics-plugins/releases) — VST3 / AU / LV2 installers for macOS and Windows
- [GitHub repository and wiki](https://github.com/schweizerweb/icst-ambisonics-plugins) — source code, issue tracker, and full technical documentation

Includes: AmbiEncoder (Mono + Multi), AmbiDecoder, MultiDecoder, Animator, and OSC support.

For installation instructions, see [Installation](/icst-ambisonics-plugins/02_installation/).

## ICST Ambisonics Tools (Max/MSP)

Ambisonics externals and patches for Max/MSP — encoding, decoding, and spatial processing objects for use in Max patches.

- [Download via Max Package Manager](https://www.zhdk.ch/forschung/icst/software-downloads-5379/downloads-ambisonics-externals-for-maxmsp-5381) — install directly from within Max using the Package Manager

Note: the ICST Ambisonics Tools are a separate package from the REAPER plugins and are maintained independently.
