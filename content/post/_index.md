This page is the practical tutorial index for ICST Ambisonics workflows in REAPER and Max-based environments.
Use it when you want step-by-step setup, OSC control patterns, automation examples, and production-ready routing guides.

### Who these OSC workflows are for
- **Composers:** spatial composition workflows with playable automation and repeatable movement design.
- **Technicians:** robust routing, synchronization, and controller integration for production and playback setups.
- **Students:** structured learning path from basic OSC syntax to complete DAW-driven Ambisonics sessions.

### Recommended prerequisites
- Basic REAPER operation (tracks, routing, monitoring).
- Basic OSC concepts (host, port, message format).
- Basic Ambisonics terms (source, B-format, encoder/decoder).
