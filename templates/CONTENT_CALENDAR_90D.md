## Operative Checkliste je Beitrag

1. DE + EN Version am selben Tag publizieren.
2. Pro Beitrag mindestens 3 interne Links setzen:
   - 1x zu Tutorials (`/post/`)
   - 1x zu Blog/Studio (`/blog/`)
   - 1x zu Download oder Ascolta
3. Einheitlicher Abschlussblock:
   - `Related Tutorial`
   - `Download`
   - `Next Step`
4. SEO-Minimum:
   - `title`
   - `description`
   - `date`
   - `tags` (3 bis 5)
5. Nach Publikation in beiden Feeds pruefen:
   - `/blog/index.xml`
   - `/post/index.xml`

## KPIs fuer den 90-Tage-Zeitraum

1. +30% Klicks von `/blog/` auf `/post/`.
2. +20% Klicks auf Download-Seiten.
3. Mindestens 3 stabile Content-Pfade mit messbarer Nutzung:
   - Start -> Tutorial -> Download
   - Blog Case -> Setup Tutorial -> Kontakt
   - Ascolta -> Kontextartikel -> Related Tutorial
